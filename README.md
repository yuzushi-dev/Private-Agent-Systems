# Private Agent Systems — Companion Repository

Companion repository for the book **Private Agent Systems: Architecture, privacy,
observability, and governance for local, hybrid, and cloud AI agents** by Daniele Verì
(first edition, June 2026). Italian edition: **Sistemi agentici privati**.

This repository hosts the supplemental material referenced on the book's copyright page:

- **[Errata](ERRATA.md)** — corrections reported after publication, by edition and printing.
- **[Source register](source-register.yaml)** — the verification snapshot for this edition.
  Every time-sensitive claim in the book (provider terms, standard versions, model
  families, tool documentation) was checked against the primary source on the date
  recorded here. Re-check the source before relying on a claim; the register tells you
  what was verified and when.

## Case-study repositories

The book uses two first-party open-source projects as case studies, read as
architecture, not as commercial endorsements:

- **[Amber](https://github.com/yuzushi-dev/Amber)** — governable Hybrid GraphRAG
  platform. Book snapshot commit: `6e6225107420f239d51044b87572c2569b9f33e6`.
- **[Relic](https://github.com/yuzushi-dev/Relic)** — runtime governance layer for
  agent memory, provenance, and consent. Book snapshot commit:
  `b8d56939af38a293b6692349726da73a8b60f41e`.

## Reporting errata

Open an issue describing the edition (EN/IT), format (print/ebook), location
(chapter and section), and the problem. Confirmed corrections are recorded in
[ERRATA.md](ERRATA.md) and applied to future printings.
